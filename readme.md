## Abstract
This project implements a novel, multi-layered deterministic decryption framework targeting the structural anomalies and low statistical entropy of the 15th-century codex known as the Voynich Manuscript (Yale, Beinecke MS 408). 

The underlying engine utilizes a four-constraint architecture:
1. **Layer 4 (The Spatial Cut - Φ):** An initial spatial filtration layer governed by the Golden Ratio (Φ = 0.618) to isolate positionally invariant null anchor tokens.
2. **Layer 3 (The Multi-Pass Ceiling):** A strict 2-pass sequential processing limit.
3. **Layer 2 (The Dual-Number Shift Loop):** A modular, word-resetting alphabetic shift engine mapping characters using combined irrational vectors derived from the Fibonacci sequence and the first five digits of Pi (π = 3.14159).
4. **Layer 1 (The Gallo-Germanic Linguistic Target):** Maps an underlying Old High German (OHG) lexical core adapted to a localized, Alpine Gallo-Italic phonetic syntax.

Without adjusting any mathematical parameters, the output text exhibits a clear semantic bridge that transitions dynamically based on adjacent illustrations, resolving text into plant morphology characteristics (*yfino*, *vehq*) on Folio 2r and fluid-dynamics compounds (*upvgt* / *upvge* → OHG *Ufguz*) on Folio 78r.
